# table-viewer

Mike, 2026-09-22 (project opened on ruling d33 a, session d6b31eed).

A browser-side module that takes one table, an array of row objects with an optional column spec, and gives it sections, enum filters, thresholds on metrics, sort by any column with a chosen direction, a column chooser, row folding instead of horizontal scroll, grouping by any column with a group within the group, a second sort for ties, and an action cell declared by the caller. No dependency, no build step.

Files:

- `table-viewer-v1.js` — the module. Exposes `mountTable(container, rows, spec, meta)` and the `TableViewer` namespace (`mountTable`, `actionButton`, `mountTextSize`, `mountViewsTblVwr`, `inferColumns`, `inferKind`, `groupingOf`, `version`). Group and Then group offer every column (rulings of 2026-10-27 and 2026-10-28): `groupingOf` groups a column by value, by letter ranges, by value bands of a round row count or by day, month or year, and grades the result by its number of groups and rows per group, the useful ones listed first; above 100 rows a finer entry gives groups an order of magnitude smaller; inner groups stay closed until tapped, and a grouping over more than 100 rows opens folded. Then sort orders the ties of Sort. `meta.sourceCount`, the rows the source holds, puts "M of T in the database" in the count line. `mountTextSize(container)` turns an empty element in a page's pinned top row into the A− A+ text-size pair, which sizes the whole page and is remembered per device (spec E14). `mountViewsTblVwr(container, { site, showSectionTblVwr })` turns an empty element in that row into the saved-view widgets (spec E15): the View dropdown, save view and delete view. A saved view is one table's filters, bounds, sort, chosen columns and group under a name, with the table's `name` and the page `section` the spec gives it; choosing a view calls the page's `showSectionTblVwr(section)` and restores the table's settings; views are kept per device under one key per page, behind a small store interface of six calls (`listViewsTblVwr`, `getViewTblVwr`, `saveViewTblVwr`, `removeViewTblVwr`, `currentViewTblVwr`, `setCurrentViewTblVwr`) a page may replace through `viewsStoreTblVwr`.
- `index.html` and `sample.json` — a demo page with two sample tables, the text-size pair, the saved-view widgets and no server: a metric table whose actions only log to the console, and a long-text registry. Serve the folder with any static server and open `index.html`.
