# table-viewer

Mike, 2026-09-22 (project opened on ruling d33 a, session d6b31eed).

A browser-side module that takes one table, an array of row objects with an optional column spec, and gives it sections, enum filters, thresholds on metrics, sort by any column with a chosen direction, a column chooser, row folding instead of horizontal scroll, grouping by any column with a group within the group, a second sort for ties, and an action cell declared by the caller. No dependency, no build step.

Files:

- `table-viewer-v1.js` — the module. Exposes `mountTable(container, rows, spec, meta)` and the `TableViewer` namespace (`mountTable`, `actionButton`, `mountTextSize`, `mountViewsTblVwr`, `inferColumns`, `inferKind`, `groupingOf`, `version`). Group and Then group offer every column (rulings of 2026-10-27 and 2026-10-28): `groupingOf` groups a column by value, by letter ranges, by value bands of a round row count or by day, month or year, and grades the result by its number of groups and rows per group, the useful ones listed first; above 100 rows a finer entry gives groups an order of magnitude smaller; inner groups stay closed until tapped, and a grouping over more than 100 rows opens folded; letter, period and band groups keep their own order whatever the sort (0–9, A to Z, "other scripts", "#", the blank group last; periods oldest first; bands low to high) and every letter outside Latin A to Z forms the one group "other scripts" (2026-10-29); a text column sorts, and its letter groups form, on one key, the text from its first letter or digit with accents folded and Ø, Æ, Œ, Ł, ß, Đ, Þ, Ħ, ı and kin folded to their base letters, so " Neurosurgical" and "@ Ascent" sort under N and A and "Ølaf" groups under O, a value with no letter or digit after every lettered one and before the blanks, while filters, display and the find box keep the raw text (2026-10-29); groups by value order by their extreme row under the sort. Then sort orders the ties of Sort. The handle `mountTable` returns carries `shownRowsTblVwr()`, the rows passing the filters and bounds in the order the table shows them under sort, then-sort and grouping, rows in folded groups included at their group's place (2026-10-29). Each control row (filters, order, columns) is one line dragged sideways with a finger, no scrollbar (2026-10-30). For a page's focus strip (spec E16) the handle also carries `summaryTblVwr()`, the table's row count, filter, bound, sort and group wordings, and `foldTblVwr()`, the fold chip's action; `TableViewer.onRenderTblVwr(fn)` calls `fn(handle)` after every render; and the class `tv-focus` on the page's document element hides every table's control rows, panels and count line. `meta.sourceCount`, the rows the source holds, puts "M of T in the database" in the count line. `mountTextSize(container)` turns an empty element in a page's pinned top row into the A− A+ text-size pair, which sizes the whole page and is remembered per device (spec E14). `mountViewsTblVwr(container, { site, showSectionTblVwr })` turns an empty element in that row into the saved-view widgets (spec E15): the View dropdown, save view and delete view. A saved view is one table's filters, bounds, sort, chosen columns and group under a name, with the table's `name` and the page `section` the spec gives it; choosing a view calls the page's `showSectionTblVwr(section)` and restores the table's settings; views are kept per device under one key per page, behind a small store interface of six calls (`listViewsTblVwr`, `getViewTblVwr`, `saveViewTblVwr`, `removeViewTblVwr`, `currentViewTblVwr`, `setCurrentViewTblVwr`) a page may replace through `viewsStoreTblVwr`.
- `table-viewer-v2.js` — version 2 (2026-10-31, spec draft 13, ruling module-page-split a): everything v1 has, each table's controls in one row per step (columns, filters, narrow, group, order; narrow and columns as rows, no panels), and `mountPageTblVwr(container, { site, title, about, entries, viewsStoreTblVwr })`, which draws the page around the tables: a pinned top row of focus, the controls status between < and > (view, table, columns, filters, narrow, group, order, notes, wrapping; every load starts at table; choosing a view or a table moves it one step forward), a count (columns at view and columns, rows elsewhere, stacked) and Z− Z+; the step's row under it (the View list with "none" and "all tables", the table chooser with the instructions, a table's rows, an entry's notes by category); save view and delete view in the window's bottom corners at the view step, delete asking in a box; focus mode with the entry's name dragged sideways. `entries` is one `{ key, name, el, notes }` per table or page section; a page with a bar at the window's bottom sets `--tv-bottom-inset`. Every clickable item is a rounded rectangle with a 2 px accent border; the text-size faces are Z− and Z+. The handle adds `countsTblVwr()` and `hasNumbersTblVwr()`. v1 stays as it is for the pages that load it (the fail-event table, the trigger master table, the demo page).
- `index.html` and `sample.json` — a demo page with two sample tables, the text-size pair, the saved-view widgets and no server: a metric table whose actions only log to the console, and a long-text registry. Serve the folder with any static server and open `index.html`.
